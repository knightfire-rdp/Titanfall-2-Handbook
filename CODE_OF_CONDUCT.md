# Code of Conduct

## Our goal

The Titanfall 2 Handbook is a community project. We want it to be a welcoming and constructive place for people who want to learn about, document, and improve Titanfall 2.

## Expected behavior

Contributors are expected to:

- Be respectful and constructive.
- Discuss ideas rather than attacking people.
- Accept reasonable corrections and feedback.
- Keep discussions relevant to the project.
- Give appropriate credit to other people's work.
- Respect the copyrights and intellectual property of others.

## Unacceptable behavior

The following is not acceptable:

- Harassment, personal attacks, or targeted insults.
- Discriminatory or hateful conduct.
- Threats or intimidation.
- Deliberately disrupting the project or its contributors.
- Submitting someone else's work as your own.
- Other behavior that would make participation unnecessarily hostile or unsafe.

## Enforcement

Project maintainers may remove, edit, reject, or restrict contributions or participation that violates this Code of Conduct.

If you encounter a problem, contact the project maintainer through the project's available GitHub contact or issue channels.

## Scope

This Code of Conduct applies to contributions, discussions, issues, pull requests, and other interactions associated with the Titanfall 2 Handbook project.
