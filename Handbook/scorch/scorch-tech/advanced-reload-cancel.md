# 🟢 Advanced Reload Cancel

Scorch is the only Titan whose reload gets faster due to the [reload cancel glitch](../../universal-mechanics/reload-cancel-and-checkpoints.md), but with this technique, you can push the limits to its final form. By combining reload cancel with the store ability glitch, you'll make Scorch reload noticeably faster while not using 5% fuel on Thermal Shield activation.

To perform this glitch, you want to store the Firewall ability and deploy the ghost animation mid-reload instead of a typical Thermal Shield reload cancel.

### <mark style="color:yellow;">**Step-by-Step Sequence**</mark>

1. <mark style="color:yellow;">Hold the “fire” key.</mark>
2. <mark style="color:yellow;">Deploy the Firewall.</mark>
3. <mark style="color:yellow;">Let go of the “fire“ key.</mark>
   1. (Firewall ghost animation is now stored until your ability replenishes.)
4. <mark style="color:yellow;">Reload your gun.</mark>
5. <mark style="color:yellow;">Press the “Firewall” key at the specific part of the reload.</mark>

{% hint style="info" %}
* The “Fuel for the Fire” kit doesn't recharge fast enough to make it worth using for this.
* You can perform this glitch only once before your ability replenishes.
{% endhint %}
