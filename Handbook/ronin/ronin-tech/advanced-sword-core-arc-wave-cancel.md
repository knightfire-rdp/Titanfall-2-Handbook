# 🟢 Advanced Sword Core Arc Wave Cancel

This page is similar to [ability-cancel.md](../../universal-mechanics/ability-cancel.md "mention") but different. This is an advanced version of regular Sword Core Arc Wave cancel; this one doesn't involve you to melee. Instead, press specific keys in a sequence.

Make sure to continue holding the Sword Block and Arc Wave keys until you let go of them later.&#x20;

### <mark style="color:yellow;">**Step-by-Step Sequence**</mark>

1. <mark style="color:yellow;">Hold Arc Wave.</mark>
2. <mark style="color:yellow;">Hold Sword Block</mark> (nothing will happen yet)<mark style="color:yellow;">.</mark>
3. <mark style="color:yellow;">Press melee</mark> (you'll block)<mark style="color:yellow;">.</mark>
4. <mark style="color:yellow;">Let go of Arc Wave</mark> (you'll continue blocking, but on release of Sword Block you won't be back in Arc Wave hold position)<mark style="color:yellow;">.</mark>
5. <mark style="color:yellow;">Let go of Sword Block</mark> (Arc Wave canceled successfully)<mark style="color:yellow;">.</mark>
