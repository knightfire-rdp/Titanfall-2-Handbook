# 🟢 Invisibility Glitch

This glitch only works in Frontier Defense but could possibly work in other modes if they ever make Aegis Attrition or any mode that will have AI alongside Aegis upgrades. Two of the methods involve the Aegis Ronin upgrade “Wraith.” It lets Ronin hold up to 2 Phase Dashes, which is precisely what you need.

## <mark style="color:yellow;">The 3 Invisibility Methods</mark>

There are multiple ways to do it. But the easier method can be done using Ronin, though you require the Aegis Wraith upgrade first.

The way the glitch works is that it creates an “extended phase” effect, making the game think you're still in phase. So yeah, your Pilot won't look invisible like Cloak Pilot, aka transparent, but it will make you seem invisible to the AI, including Auto-Titans.

It does work as Pilot and also when piloting a Titan, but only when you're inside of it. They'll still see your Auto-Titan.

#### <mark style="color:yellow;">Key Features</mark>

* <mark style="color:yellow;">Works as Pilot, but also when piloting a Titan.</mark>
* <mark style="color:yellow;">Does not work on your Auto-Titan.</mark>
* <mark style="color:yellow;">Works like an extended Phase effect.</mark>
* <mark style="color:yellow;">Makes you invisible to all AI, even Auto-Titans.</mark>
* <mark style="color:yellow;">You lose the effect on death or when you get redeployed due to the Harvester being destroyed.</mark>

### <mark style="color:yellow;">Pilot Double Phase Method</mark> (Hardest)

When? At the start of the match and between waves.

The timing can be rough, but this is a pretty safe method to get invisibility without a need for a Titan. This one can be done only at the start of the match and during intermissions, so in between waves when you can go shop.

You must chain phases with zero gap. The difficulty comes down to the timing; you must phase before the first phase fully ends.

#### <mark style="color:yellow;">Step-by-Step Sequence</mark>

1. <mark style="color:yellow;">Equip 2 Phase Shift Pilot loadouts.</mark>
2. <mark style="color:yellow;">During intermission, activate phase.</mark>
3. <mark style="color:yellow;">Immediately switch to the other Phase Pilot Loadout.</mark>
4. <mark style="color:yellow;">Phase again.</mark>



### <mark style="color:yellow;">Ronin Double Phase Method</mark> (Easiest)

When? After wave 1.

Pretty self-explanatory, to be honest. Phasing quickly twice in a row lets you turn invisible. Though you do need a Ronin with the Wraith Aegis upgrade. So it's less accessible than the Phase Pilot method. When disembarking your Ronin, you'll still have the invisibility, but your Auto-Titan Ronin won't.

#### <mark style="color:yellow;">Step-by-Step Sequence</mark>

1. <mark style="color:yellow;">Be inside of Ronin with the Wraith Aegis upgrade.</mark>
2. <mark style="color:yellow;">Spam the Phase Dash ability twice in a row.</mark>



### <mark style="color:yellow;">Ronin Rodeo Method</mark> (Backup Strategy)

When? After wave 1 and with teammate's help.

It's based on the “Ronin Double Phase Method.” The person that wishes to become invisible needs to rodeo a teammate Ronin that has the Wraith Aegis upgrade. The Ronin needs to do the double phase, and then the Pilot will be invisible as well. The Ronin doesn't need to be invisible already to do this method. This is a lot more annoying to do, since you need to coordinate the phasing with the Pilot.

#### <mark style="color:yellow;">Step-by-Step Sequence</mark>

1. <mark style="color:yellow;">Rodeo a teammate Ronin that has the Wraith Aegis Upgrade.</mark>
2. <mark style="color:yellow;">Have the Ronin spam phase twice in a row, like in the “Ronin Double Phase Method.”</mark>
