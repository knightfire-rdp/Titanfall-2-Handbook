# 🔻 MTMS Last Missile Not Firing Bug

For some reason, when [blind firing](#user-content-fn-1)[^1] the Multi-Target Missile System, the last missile will not fire. This is an odd bug that prevents you from destroying Tone's reinforced Particle Wall in one missile barrage<sup><mark style="color:orange;">**⟨1⟩**<mark style="color:orange;"></sup>, unlike the Missile Rack.&#x20;

{% hint style="info" %}
<sup><mark style="color:orange;">**⟨1⟩**<mark style="color:orange;"></sup> <mark style="color:yellow;">Assuming you have Missile Rack with MTMS.</mark>
{% endhint %}

### <mark style="color:yellow;">Ways to Get Around the Bug</mark>

* <mark style="color:yellow;">Fire the missiles locked onto the Titan.</mark>
* <mark style="color:yellow;">Finish off the Particle Wall with the XO-16 Chaingun.</mark>
* <mark style="color:yellow;">Use a different 3rd Core Upgrade.</mark>
