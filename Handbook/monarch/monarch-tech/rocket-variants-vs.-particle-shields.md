# ℹ️ Rocket Variants vs. Particle Shields

Monarch's missiles shred Gun Shield, Particle Wall, and Pilot shield abilities. Sometimes one barrage won't suffice; you can always finish it off with the XO-16 Chaingun. This page is simply a more in-depth version of the [titan-ability-interactions.md](../../universal-mechanics/titan-ability-interactions.md "mention") page, but only centered around Monarch's missiles.&#x20;

Here are all the methods for dealing with said shields. Beware that the Multi-Target Missile System will deal less damage when blindfired because of the [one missile not getting fired bug.](mtms-last-missile-not-firing-bug.md)&#x20;

### <mark style="color:yellow;">For Reference</mark>

<mark style="color:yellow;">Terms</mark>\
<mark style="color:yellow;">RS</mark> = Rocket Salvo\
<mark style="color:yellow;">MR</mark> = Missile Rack\
<mark style="color:yellow;">MTMS</mark> = Multi-Target Missile System \
<mark style="color:yellow;">Bullets and Mag</mark> = XO-16 Chaingun bullets and magazine



<mark style="color:yellow;">Entity Health</mark>\
Particle Wall = 2,000 HP\
Reinforced Particle Wall = 3,000 HP\
Gun Shield = 2,500 HP\
Bulwark = 5,000 HP\
A-Wall = 1000 HP\
Hard Cover = 850 HP



<mark style="color:yellow;">Entity Damage</mark>\
XO-16 = 45 damage\
Rocket Salvo = 1,500 damage\
Missile Rack = 3,000 damage\
Multi-Target Missile System = 2,750 damage ([3,000 with lock-on](mtms-last-missile-not-firing-bug.md))
