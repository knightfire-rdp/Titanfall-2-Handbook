# 🔰 Flame Core Narrowing

:beginner:”Ability to change Flame Core wave spread width, making it easier to dodge or catch, but can also reduce the chance of it hitting the walls instead.”

Flame Core will fire the 3 waves the widest when looking directly forwards. The more you look up or down, the tighter the spread will be on the waves. Countary to what people people, narrow Flame Cores are not always bad, can be useful in certain situations.

Be careful when narrowing the Flame Core because not only does it become easier to dodge but also possible to block it with [Flame Shield](blocking-wave-attacks-with-thermal-shield.md#blocking-flame-core) and Vortex Shield if it's narrow enough.
