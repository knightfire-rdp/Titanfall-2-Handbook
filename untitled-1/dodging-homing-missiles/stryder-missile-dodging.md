# ▫️🚀Stryder Missile Dodging

Make sure to read [“Dodging Homing Missiles”](./) for context

## <mark style="color:yellow;">Directly Fired Archer Missile:</mark>

* [ ] Dodge while walking left.
* [x] Sword Block left (only way to dodge left while walking).
* [x] Dodge while walking right.
* [x] Dodge with sprint.
* [x] Dodge with a dash forwards at a 45-60 degree angle.&#x20;
* [ ] Bad Dash.
