# 🚀 Dodging Homing Missiles

You can dodge all 4 types of homing missiles in the game with any Titan chassis, it's all dependent on the angle the missile came from and the dodge movement.

You can dodge Archer missiles, Tone Tracker missiles, MTMS missiles (Multi Target Missile System), and Salvo Core missiles.

For now, there are only Archer and Tone Tracker missiles documented.&#x20;

## <mark style="color:yellow;">Why Right Side Is Better</mark>

Dodging the left side is a lot harder since Tone Tracker missiles, Archer missiles, and MTMS missiles are fired from the enemy's right side. Which in turn makes the missiles require to curve a lot more to hit you if you go the opposite direction (your right). Some missiles can't be dodged from the left side at all.

A good example of the difference is the Ronin Sword Block dodge. Sword Block for some reason causes the missiles to aim slightly elsewhere, making a normally not possible dodge possible.&#x20;
