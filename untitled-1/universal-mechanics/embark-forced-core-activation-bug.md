# 🔻 Embark Forced Core Activation Bug

Basically, holding defensive and ordnance ability keys at the same time while embarking a Titan that has a core ready will cause that Titan to force activate said core. The bug surprisingly doesn't work on Ion and Scorch.

### <mark style="color:yellow;">Key Features</mark>

* <mark style="color:yellow;">Holding ordnance and defensive ability keys together at the same time while embarking a Titan with a core ready, it will forcefully activate the core.</mark>
* <mark style="color:yellow;">The Bug causes a Titan to forcefully activate their core if one is present.</mark>
* <mark style="color:yellow;">Affects all Titans except for Ion and Scorch.</mark>
